# security-portfolio

A collection of hands-on cybersecurity projects and labs covering offensive and defensive security, network analysis, and incident response.

## Contents

- **Brute_Force_Attacks** — Demonstrations and notes on brute-force attack techniques and mitigations.
- **Cisco_Packet_Tracer** — Network simulation labs and configurations built in Cisco Packet Tracer.
- **Incident_Response_Case_Study** — Walkthrough of a security incident, from detection to remediation.
- **Social_Engineering** — Research and exercises on social engineering tactics and awareness.
- **Web_Application_Scan** — Vulnerability scanning and assessment of web applications.
- **nmap** — Network reconnaissance and port scanning exercises using Nmap.
- **wazuh-lab** — SIEM setup and threat detection lab using Wazuh.

## About

This repository showcases practical skills in penetration testing, network security, threat detection, and incident response, developed through self-directed labs and case studies.
